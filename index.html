ARTICLE 0119 SEPT. 2026

LINUX · RED HAT

Vulnérabilités du noyau Linux – Red Hat

Le bulletin RHSB-2026-011, publié le 19 septembre et mis à jour le 21 septembre 2026, présente quatre failles touchant notamment des composants réseau du noyau Linux et plusieurs versions de RHEL (7 à 10).

Lire mon analyse +

CVE suivies : CVE-2026-80844, CVE-2026-81000, CVE-2026-68121 et CVE-2026-74469.

Risques : élévation de privilèges jusqu'aux droits root pour un utilisateur local ; la faille DiagSpill peut aussi entraîner une corruption de mémoire et un déni de service.

Mesures : identifier les systèmes concernés et appliquer les mises à jour de sécurité Red Hat. Des mesures temporaires sont possibles, mais peuvent perturber certains services.

Ce que je retiens : une veille régulière sur les CVE permet de mieux protéger les serveurs Linux.

Travail réalisé avec Théo Huguenin et Noa Bauvais.

Bulletin officiel Red Hat ↗
ARTICLE 0209 SEPT. 2026

WINDOWS SERVER · CERT-FR

Multiples vulnérabilités dans Microsoft Windows Server

L'avis CERTFR-2026-AVI-1147 signale des risques d'exécution de code à distance, d'élévation de privilèges et de déni de service, notamment sur Windows Server 2019, 2022 et 2025.

Lire mon analyse +

CVE citées : CVE-2026-83501, CVE-2026-83983 et CVE-2026-83989.

Failles exploitées : selon l'avis résumé dans mon document, Microsoft indique que les CVE-2026-81963 et CVE-2026-85880 font l'objet d'exploitations actives.

Risques : une attaque peut permettre l'exécution de code ou l'obtention de privilèges supplémentaires sur un serveur vulnérable.

Mesures : contrôler les versions des serveurs, consulter les avis Microsoft et installer les correctifs adaptés sans tarder.

Ce que je retiens : la surveillance des CVE facilite la priorisation des mises à jour sur une infrastructure Windows Server.

Avis officiel CERT-FR ↗
ARTICLE 0309 SEPT. 2026

WINDOWS · ANALYSE GÉNÉRALE

Multiples vulnérabilités dans Microsoft Windows

Une analyse plus générale du même avis CERTFR-2026-AVI-1147, concernant aussi bien des postes Windows 10/11 que plusieurs générations de Windows Server, selon les failles.

Lire mon analyse +

Risques : exécution de code malveillant, élévation de privilèges, vol ou modification de données, ainsi que déni de service.

Systèmes mentionnés : Windows 10, Windows 11 et Windows Server 2012, 2016, 2019, 2022 et 2025, selon les vulnérabilités.

Solutions : appliquer les correctifs Microsoft, vérifier les versions utilisées et surveiller les journaux système afin de détecter une activité suspecte.

Ce que je retiens : une politique de mises à jour régulières protège les postes, les serveurs et les données de l'entreprise.
